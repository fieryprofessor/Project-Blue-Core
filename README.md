# 🔷 Project Blue Core

### A Retro-Style 2D Action Platformer Built with Godot

**Project Blue Core** is a 2D action-platformer inspired by classic NES-era games. The project aims to recreate the nostalgic feel of retro gaming through pixel art, challenging platforming, projectile-based combat, enemy encounters, and boss battles.

Built using **Godot Engine 4** and GDScript, the game focuses on responsive controls, classic gameplay mechanics, and an authentic retro-inspired experience.

> 🚧 **Status:** In Development  
> 🎮 **Current Focus:** First Campaign  
> 🛠️ **Engine:** Godot Engine 4  
> 💻 **Language:** GDScript
